# Brand

The mark is a ring that opens toward a dot: the detector's scan, and the launchpad that is not on any list yet.

| File                                                       | Use                                                                                        |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `mark.svg`                                                 | the mark, `currentColor` (set `color` on the parent)                                       |
| `mark-accent.svg`                                          | the mark in the accent blue `#1F3FFF`                                                      |
| `wordmark.svg`                                             | `launchpad-registry` as outlined paths (Inter Tight Bold, −3.5 % tracking), `currentColor` |
| `lockup-dark.svg` / `lockup-light.svg` / `lockup-mono.svg` | mark + wordmark on dark / light / single colour                                            |
| `mark-16.png` … `mark-512.png`                             | favicon and app icons                                                                      |

Colours: ink `#0B0D12`, paper `#F4F5F7`, accent `#7C9CFF` on dark, `#1F3FFF` on light. Typeface: Inter Tight (SIL OFL 1.1) for the wordmark, Inter for text, JetBrains Mono for code.
Keep the mark at least 16 px, with clear space of half its height around it. Do not rotate it, outline it, or add gradients or shadows.
