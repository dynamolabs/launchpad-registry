# launchpad-registry — agent notes

- Data lives in `registry/<chain>/<id>.json`; `dist/`, `docs/index.html` are generated by `npm run build` and must be committed.
- Always run `npm run validate && npm run verify -- --write && npm run build && npm test && npm run format` before committing data changes (`verify --write` and `fixtures` rewrite JSON in a layout Prettier rejects, and CI lints every file); `npm run lint` (ESLint + Prettier) for code changes, and read its exit code, not a grep of its output.
- Code: shared helpers in `lib/`, detector logic as pure exported functions with offline tests in `test/` (recorded RPC answers in `test/fixtures/`). CLI entry points are guarded with `isMain(import.meta.url)`.
- Use `skills/add-launchpad/SKILL.md` to add entries. Never invent addresses: every address must be verified on-chain (`npm run verify`) and backed by a `sources` link.
- Shared DEX programs (graduation targets) use role `other`; they may appear in many entries.
